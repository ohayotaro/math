# 研究調査・応用評価 — Spectra v0

## 結論

このコレクションから、暗号方式を新設するのではなく、**検査可能な疎接続ネットワーク**を
構築する方針を選んだ。成果131の次数保存switch kernelで候補を作り、成果178の論文にある
厳密な正定値検査で採用可否を決める。台帳側はEd25519署名と固定メンバーの署名クォーラムを使う。

研究成果の応用は実装されるが、研究の新定理そのものを再証明したわけではない。
また、switch操作もスペクトル検査もそれ自体は既存の数学的道具である。
本プロジェクトはその論文に記された具体的なkernelと検査式を組み合わせた設計であり、
新しい暗号資産の安全性・経済的価値・先行技術に対する独創性を証明するものではない。

## 採用した成果の根拠と限界

### 131 — 次数を保った接続候補の生成

原論文:
[Polynomial mixing of the switch chain for every graphical degree sequence](../../../preprints/Polynomial-Mixing-of-the-Switch-Chain-for-Every-Graphical-Degree-Sequence-September-25-2026/main.pdf)
の[導入とkernel](../../../preprints/Polynomial-Mixing-of-the-Switch-Chain-for-Every-Graphical-Degree-Sequence-September-25-2026/build/sections/introduction.tex)。

1. 確率1/2で何もしない。
2. 残りの確率で4頂点集合を一様に選択する。
3. その4点上の3種類の完全マッチングから、異なる順序対を6通り等確率で選ぶ。
4. 削除辺があり、挿入辺がない場合のみ交換する。

実装は [switch_step](../spectra/topology.py)。次数保存によりpeer数を一定にできる。
ただし生成過程では非連結グラフも許す。途中で連結性によって棄却すると原論文とは
異なるMarkov連鎖になるため、最終候補だけを別途検査する。

論文の `t_mix <= 2 n^8` はTV距離1/4の主張である。8頂点でも上界は33,554,432ステップ。
実装の1,000ステップを「混合済み」「一様」「安全な無作為委員会」とは呼ばない。
さらに最終候補のスペクトル選別も分布を変える。公開seedは再現性用で、秘匿乱数ではない。

[Leanスコープ説明](../../../lean/docs/131.md) は混合・gap・連結性に限定され、
exact uniform samplerの全体は対象外。
[Comparator設定](../../../lean/ComparatorChallenges/SwitchChain.json) は
`OAI.Probability.SwitchChain.Main` の3定理を指定している。
[実際の主定理ソース](../../../lean/OAI/Probability/SwitchChain/Main.lean) は証明を持つが、
今回そのimport閉包の再ビルドやaxiom検査は実施していない。
ComparatorChallenges側の`by sorry`は比較対象の仕様であり、それだけを理由に
解の証明が欠けていると判定しない。一方、形式化ファイルの存在だけで再検証済みとも扱わない。

### 178 — 浮動小数点に頼らない接続グラフの採否検査

原論文:
[Deterministic nonbipartite Ramanujan graphs in every fixed degree](../../../preprints/Deterministic-nonbipartite-Ramanujan-graphs-in-every-fixed-degree-September-23-2026/paper.pdf)
の[アルゴリズム節](../../../preprints/Deterministic-nonbipartite-Ramanujan-graphs-in-every-fixed-degree-September-23-2026/build/sections/algorithm.tex)。

単純d正則グラフの隣接行列をA、`B=[e1-en,…,e(n-1)-en]`とする。
論文の最終検査式をそのまま採用する:

`Bᵀ(4(d−1)I−A²)B ≻ 0`。

Bは定数ベクトルに直交する空間の有理基底なので、この条件は非自明固有値の絶対値が
`2√(d−1)`より厳密に小さいことと同値。正則性の検査を省略してはいけない。
`fractions.Fraction`でLDLの全pivotが正であることを検査し、ゼロ境界は不合格とする。
この有限検査自体は原論文の大規模な存在証明・構成アルゴリズムが正しいかとは独立している。

実装は[spectral_certificate](../spectra/topology.py)。原論文の全段階の構成・修復は未移植。
上限付きの候補探索が失敗したら停止し、任意サイズで成功すると主張しない。
主張の適用条件「d固定、十分大きい偶数n、多項式次数はd依存」を、小さなnでも
無条件に成功するという意味に読み替えない。系列178のLeanスコープは索引に見つからなかった。

## 有限グラフ実験

[再現スクリプト](../tools/evaluate_topology.py) と [保存した生データ](topology-results.json)。
seed=131178、次数4、1試行1,000switch、最大100試行を事前固定した。
生成・検査の実行結果は次の通り。これは3つの固定例であり、統計的な平均性能ではない。

|n|採用辺数 / 完全グラフ|辺数削減|採用グラフ直径 / 同次数ring直径|厳密検査|全組合せの除去耐性|
|---|---|---|---|---|---|
|8|16 / 28|42.9%|2 / 2|合格、ringも合格|最大2点、37集合すべて接続|
|16|32 / 120|73.3%|3 / 4|合格、ringも合格|最大3点、697集合すべて接続|
|32|64 / 496|87.1%|5 / 8|合格、ring不合格|最大3点、5,489集合すべて接続|

32頂点の平均最短距離は採用例が325/124≒2.621、同次数ringが136/31≒4.387。
8頂点ではringに対する距離改善はない。完全グラフに比べればすべてhop数は増える。
辺数削減を取引TPS・通信総量の向上と言い換えない。ノード除去後の接続性だけでは
経路探索やリーダー生存、quorum到達を保証しない。16/32頂点の除去検査は3点までであり、
一般的な`floor((n−1)/3)`点耐性を証明したものではない。

8頂点の厳密検査はLDLだけでなく、独立したLeibniz行列式計算でも照合した。
先頭主座小行列式は
`18, 260, 3528, 40960, 513920, 4999680, 47923200`で、すべて正。
負例として二部正則グラフ・非連結正則グラフ・半正定値境界を拒否するテストを用意した。

## 開発版と公開網の隔たり

実装範囲と脅威モデルは [DESIGN.md](DESIGN.md) を参照。
固定リーダー、固定メンバー、ローカル通信、独立プロセス・独立DBの開発版である。
障害時にquorumを下げて進めず停止する。view change、許可不要参加、PoS、
罰則・報酬の経済設計、耐量子署名、Eclipse/DoS対策、本番鍵管理は未提供。

次の段階は、(1)研究の外部検証と形式証明の再実行、(2)実績あるBFTエンジンに接続層を
差し替えて多ホストで測定、(3)adversarial routing・churn・data availability・
経済設計の評価、の順序が妥当。全論文の詳細精査を行う場合は、一次台帳を入力に
分野別の独立調査を実施し、証明条件・構成可能性・実装コストを追加する必要がある。
